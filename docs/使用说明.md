# 清朗防护 ClearWebGuard 1.0

适用于 Windows 10 / 11 64 位，使用系统自带的 .NET Framework 4.x 和 Windows PowerShell 5.1。无需安装 Python 或开发环境。

## 开始使用

1. 双击 `ClearWebGuard.exe`，查看中文管理界面。
2. 黑名单内置 `missav.ws` 和 `123av.com`。可每行添加一个域名，不要输入网址路径。当前版本只追加黑名单，避免误删限制。
3. 点击“安装 / 加固防护”，通过 Windows 管理员授权。首次安装会检查过滤 DNS 的可用性并保存原配置。
4. 保存工作后重新启动浏览器，点击“检测当前状态”核对结果。
5. 后续可从开始菜单打开 ClearWebGuard。关闭界面不会撤销系统规则。

## 防卸载如何生效

程序安装到 `C:\Program Files\ClearWebGuard`；配置备份存放在 `C:\ProgramData\ClearWebGuard`。安装时为这两个目录设置权限：普通 Users 组只有读取和执行权限，Administrators 和 SYSTEM 有完全控制权限。

安装、修改和卸载调用 Windows 管理员授权。标准用户不能通过本程序卸载，也不能正常删除受保护的安装文件或修改机器级规则。卸载入口公开保留在 Windows“已安装的应用”和程序界面中。

**这不是“永远无法卸载”的系统。管理员仍能解除限制。** 要让防卸载对你本人有效，请由可信任的人持有独立管理员账户和密码，你日常使用标准账户。程序不会擅自更改你的 Windows 密码或账户类型，也不使用隐藏进程、自我重装、禁止安全软件或破坏系统恢复等机制。

## 防护范围

- 对当前检测到的物理有线和无线网卡设置 Cloudflare Families 成人内容过滤 DNS，同时配置 IPv4 / IPv6。
- 使用系统 hosts 为黑名单的主域名和 www 地址添加规则；hosts 本身不支持任意子域名通配。
- 给 Chrome / Edge 写入机器级 URLBlocklist，并关闭这两个浏览器的自选 DNS-over-HTTPS，使用系统解析。
- 浏览器域名策略可覆盖对应子域名；本程序的检测只核对策略是否写入，不自动证明浏览器已加载。
- DNS 查询由 Cloudflare 处理；不收集或上传浏览历史。分类数据库可能有漏拦或误拦。
- 无法保证拦截所有色情内容、所有浏览器或所有联网方式。新增网卡不会被自动管理；更换硬件后请再次加固。

## 卸载与恢复

由管理员点击“管理员卸载”，或从 Windows“已安装的应用”卸载。程序会移除自己标记的 hosts 区块，并恢复自己修改且仍保持本程序值的 DNS / 浏览器设置。若其他管理员后来改过某项设置，会尽量保留该项更改。

**在安装本程序之前已有的屏蔽，会被当作原配置保留。卸载本程序不等于解除此前的限制。** 卸载后会保留归档配置备份，供管理员排查问题。安装目录可能留下空目录；交付文件夹中的原始 EXE 和源码不会被删除。

## 源码

源码与构建脚本在“源码”目录；运行 `build.ps1` 可使用 Windows 自带 C# 编译器重新构建。`test-engine.ps1` 在随机临时目录和随机用户注册表键下测试；真实 DNS、系统 hosts、机器策略均使用替身。
